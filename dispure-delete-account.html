DISPURE 계정 삭제 안내

FlowSoftLabs · 시행일: 2026년 8월 28일

DISPURE 이용자는 앱 안에서 직접 회원탈퇴를 실행하거나, 앱을 사용할 수 없는 경우 이메일로 계정 삭제를 요청할 수 있습니다.

1. 앱에서 직접 삭제

DISPURE 실행 → 설정 → 계정 → 회원탈퇴

회원탈퇴 확인 후 계정 삭제 절차가 진행됩니다.

2. 앱을 사용할 수 없는 경우

아래 이메일로 계정 삭제 요청을 보내주세요.

rlarudfo87@gmail.com

요청 시 DISPURE에서 사용한 Google 로그인 이메일 주소를 함께 알려주세요. 계정 소유 확인에 필요한 최소한의 추가 정보를 요청할 수 있습니다.

3. 삭제되는 서버 데이터

  • DISPURE 인증 계정
  • 프로필 정보 및 프로필 이미지
  • 공개 굿즈 및 공개용 이미지
  • 좋아요 및 댓글
  • 신고 및 차단 관계 등 계정과 연결된 서버 데이터

4. 기기 내부 데이터

DISPURE의 개인 굿즈 기록과 원본 사진 등 일부 데이터는 사용자 기기에 로컬로 저장됩니다. 회원탈퇴는 서버 계정 및 서버 데이터를 삭제하는 기능이며, 기기에 남은 로컬 데이터는 앱 데이터 삭제 또는 앱 제거 등을 통해 사용자가 직접 삭제할 수 있습니다.

5. 처리 기간

앱 내 회원탈퇴는 정상 처리되면 즉시 계정 삭제 절차가 진행됩니다. 이메일로 접수한 삭제 요청은 계정 소유 확인 후 처리합니다.
